# rekuiper Helm Chart
A lightweight, high-performance edge streaming SQL engine for Kubernetes.

![Version: 1.5.0](https://img.shields.io/badge/Version-1.5.0-informational?style=flat-square) ![Type: application](https://img.shields.io/badge/Type-application-informational?style=flat-square) ![AppVersion: 0.506--beta](https://img.shields.io/badge/AppVersion-0.506--beta-informational?style=flat-square)

## Install the Chart

```bash
git clone https://github.com/ankur-paan/rekuiper.git
cd rekuiper
helm install rekuiper deploy/chart/ekuiper
```

## Custom Values Example

```bash
helm install rekuiper deploy/chart/ekuiper \
  --set image.repository=ankurkrp/rekuiper \
  --set image.tag=0.506-beta
```

## Uninstall Chart

```bash
helm uninstall rekuiper
```
